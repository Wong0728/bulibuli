从发现变化到完成归档，一套本地工具覆盖日常守护。数据路径清晰，运行方式简单。

UP 主监控

定时检查关注对象，把新视频、新动态和变化及时收进本地队列。

视频补档

直播录制

需要时开始录制，结束后自动收尾；不依赖浏览器一直开着窗口。

弹幕与字幕

把观看现场一起保存，导出弹幕与 SRT，让归档不只是一个视频文件。

ready when you are

现在就把它
装进你的设备。

Linux / Termux 支持一条命令安装；桌面平台可以直接前往 Releases 下载对应归档。

Linux · 一键安装
$ curl -fsSL https://raw.githubusercontent.com/Wong0728/bulibuli/main/deploy/linux/install.sh | bash

安装器会校验 Release 的 SHA-256，并优先选择完整 portable 包；需要固定版本时可在命令前设置 BULIBULI_VERSION。

Termux Android arm64 · 云端预编译
$ curl -fsSL https://raw.githubusercontent.com/Wong0728/bulibuli/main/deploy/termux/install.sh | bash

下载并校验云端编译好的包，只需通过 Termux pkg 安装 curl、Python、aria2 和 FFmpeg。
