# 分支与文档约定

## `main`

主开发分支。产品源码、前端、构建脚本、CI、用户文档和公开 Hero 页面都以这里为准。后续功能开发、修复和常规 Git 提交默认在此进行。

## `promo-video`

宣传视频专用分支，从 `main` 派生。它额外保存 `docs/promo/` 的视频预览、配乐、脚本、测试和素材工具，不参与主线产品开发。

> 注：该分支目前只存在于本地，尚未推送到 GitHub 云端；需要公开宣传素材时再推送并验证。

宣传分支需要同步主线时，先在 `main` 完成并验证产品改动，再把 `main` 合并或变基到本分支；不要把宣传分支反向合并进主线。

## 文档目录

- `docs/user/`：两条分支共用的用户文档和分支约定。
- `docs/skill.md`：运行时生成并由测试校验的 AI Skill 文档，保持在公开树中。
- `docs/developer/`：本机开发者笔记、审计和临时方案，已被 `.gitignore` 忽略，不会上传到 GitHub 或 Pages。
